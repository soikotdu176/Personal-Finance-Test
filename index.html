Excel & Budge CSV Migration

Import an Assets & Liabilities, Income & Expenses or Budge export (.xlsx, .xls, .csv). Header rows are detected automatically, re-imports skip duplicates and the original files are never modified.

No PDF selected

Optional: the chosen PDF is attached to every record the next import creates. It is stored exactly like a receipt uploaded in the Add/Edit form, so viewing, downloading, deleting and backing up work the same. Leave it empty to import without attachments.

Every dropdown is dependent and sourced from Manage Categories: Type > Category * > Subcategory (plus Entry Type * > Major Head > Category * > Subcategory on the Income & Expenses sheet). Funded from Asset Subcategory lists the Asset subcategories and rejects input on Cash & Bank Account rows. The Assets & Liabilities options live on a hidden Lists sheet, and Export produces the same layout, so it can be re-imported without duplicates.

Migration History

Each import is tracked as a batch. Deleting a batch also removes the records it imported.

Office Purchase & Bill

Import the FY-wise Office Purchase & Bill.xlsx workbook (sheets such as 2025-26, left cash outflow / right cash inflow). Import opens a confirmation popup: tick I Do not want to change Account to add the rows to this ledger only, or leave it unticked to also move the linked Cash & Bank account balances. Rows are deduplicated and each import is tracked as a migration batch.

The template has Entry Type * and Category * dropdowns in every FY sheet; Export produces the same side-by-side layout, so the file can be re-imported without duplicates.

Income Tax Workbook

Import the FY-wise IT Summary workbook (sheets Summary, Exependiture, Source of Fund, Rebate, Assets, Liabilities, Tax Deduction). The imported lines are stored per Financial Year and shown as Tax Return values across the Income Tax pages; Records and Income & Expenses are not changed.

Import detects the FY from the sheet title (e.g. 2025-26), FY-suffixed sheet names (Summary 2025-26) or a Fiscal Year / Income Year column. Export combines live app data with this FY's tax overrides and manual entries in the same layout, so it can be re-imported.

Migration History

Each IT workbook import is tracked as a batch. Deleting a batch also removes the tax-return lines it imported.

Full Backup & Restore

Create a portable ZIP package with every record, category, setting and attached PDF, or restore a backup you saved earlier.

Google Drive Sync

Back up records, the protected category tree and attached PDFs to the PersonalFinance_Backups folder in your Google Drive. The latest 15 backups are kept, plus one per day (last 7 days) and one per week (last 4 weeks). Unchanged data is not uploaded again, and a safety copy of your current data is saved before every restore. With several devices, Drive is checked before every upload so older data never overwrites newer data.
